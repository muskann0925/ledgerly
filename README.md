# Billing Platform

A full-stack billing management platform designed to help businesses manage clients, invoices, payments, expenses, and financial insights efficiently.

## Features

* User authentication and role-based access
* Dashboard with revenue, payments, expenses, and analytics
* Client management
* Invoice creation and management
* PDF invoice generation
* Payment tracking
* Expense management
* Reports and financial summaries
* Email notifications

## Tech Stack

**Frontend**

* React
* TypeScript
* Vite
* Tailwind CSS
* ShadCN UI

**Backend**

* Node.js
* Express.js
* TypeScript
* Prisma ORM
* PostgreSQL

## Setup

Clone the repository:

```bash
git clone <repository-url>
```

Install dependencies:

```bash
npm install
```

Create a `.env` file using `.env.example` and add your required environment variables.

Run the application:

```bash
npm run dev
```
